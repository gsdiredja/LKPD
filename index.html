AKTIVITAS 02 MENGENAL STRUKTUR REKURSI

Rekursi adalah teknik di mana fungsi memanggil dirinya sendiri. Sebuah fungsi rekursif wajib memiliki 2 bagian penting:

1. BASE CASE (Kondisi Berhenti)
if (n == 0) {
    return;
}
2. RECURSIVE CASE (Pemanggilan)
// Memanggil fungsi untuk data n/2
desimalKeBiner(n / 2);
